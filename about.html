About The SMP

Public

GreenLime SMP is a cozy spark of chaos, where chill survival meets bold adventures and stories unfold naturally.

Running on Java 1.18.2 , the server stays true to classic Minecraft while adding featured systems that improve the overall experience.

Build freely, experiment with redstone, explore massive lands, create lore, form alliances, and simply vibe with others.

The community is welcoming, fair, and beginner-friendly — competitive when it’s fun, calm when it matters.

Both premium and cracked players can join because good worlds should be open to everyone.
